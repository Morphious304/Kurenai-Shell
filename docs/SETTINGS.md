# KURENAI Settings

[Back to the README](../README.md)

An ordinary application, "KURENAI Settings", that shows up in Rofi (drun) and in the shell's launcher. It is its own small
Quickshell config (`qs -c kurenai-settings`), so it opens and works **with the shell stopped**.

```
kurenai-settings           open it
kurenai-settings --debug   open it in this terminal with the live log (to see a QML error)
```

## The rules it follows

- **It only runs the `kurenai-*` programs** (`kurenai-ctl`, `kurenai-conf`, `kurenai-hypr`, `kurenai-clip`), with the arguments as a list, never a shell string. A value typed into a box can never become a command. Anything else is refused inside the window.
- **Every control can show its command** ("Show command" under it). The **Output** drawer (Ctrl+J) lists every command it ran, in the order it ran them, with what it printed. Nothing is hidden: you can type the same thing in a terminal.
- **It stores nothing of its own.** What you see is read back from the programs. A setting is shown at once and confirmed by reading it back, so if `kurenai-conf` refuses a value, the box goes back.
- **Anything that cannot be undone asks twice** (the button turns into "Click again to confirm" for 4 seconds).
- **Display changes have a safety timer** (see Display and input).

## The pages

| Page | What it does | Runs |
|---|---|---|
| Overview | shell running or not, Start / Stop / Restart, health check, bind check, backup, which hooks are active, which programs were found | `kurenai-ctl start/stop/restart/validate/binds-check/backup/status --json` |
| Colours | follow the wallpaper on/off, scheme (9), accent, contrast, Hyprland borders and Rofi follow, recolour now, reset | `kurenai-ctl theme ...` |
| App colours | attach / detach kitty, GTK, Qt, btop, yazi, zathura, Neovim, Spicetify, Firefox; follow wallpaper; apply now; Firefox start page and script layer | `kurenai-ctl theme extra(s) ...` |
| Wallpaper | thumbnails of your wallpaper folders (click to set), folders, transition, Walls tab options | `kurenai-ctl wallpaper list/set/current`, `kurenai-conf` |
| Launcher | behaviour settings, favourites and Prime favourites (add, reorder, remove), clear recents, reset | `kurenai-conf set/fav/recent`, `kurenai-ctl reset-launcher` |
| Rofi | is the KURENAI theme installed and used; follow the colours | `kurenai-ctl rofi-theme`, `theme rofi` |
| Bar and panels | every panel, OSD, system monitor, power and shortcuts-page setting | `kurenai-conf set` |
| Notifications | popup settings, who owns notifications, take over, restore | `kurenai-conf`, `kurenai-ctl notif-*` |
| Clipboard | panel settings, recording state, pause / resume, purge by age, unpin all, wipe | `kurenai-conf`, `kurenai-clip`, `kurenai-ctl clip-status` |
| Keybinds | KURENAI's binds: remap, switch off, reset; enable / disable the binds hook; clash check | `kurenai-conf binds ...`, `kurenai-ctl binds-check/enable-binds/disable-binds` |
| Startup and hooks | the five marked lines in `hyprland.lua` (autostart, binds, theme, lock, monitors/input); rollback; restore | `kurenai-ctl enable-*/disable-*/rollback/restore` |
| Lock screen | lock settings, start / stop, preview, lock now, restart, sync theme, reset, diagnose, hypridle report, hardening steps (printed only) | `kurenai-conf`, `kurenai-ctl lock-*` |
| Display and input | monitors (mode, position, scale, rotation, VRR, off), keyboard, mouse, touchpad; Apply with a revert timer | `kurenai-hypr ...` |
| Backup and restore | list backups, back up now, export / import your settings, reset all, where things live | `kurenai-ctl backup(s)`, `kurenai-conf export/import/reset/path` |
| Logs and checks | shell log, health check, status | `kurenai-ctl logs/validate/status` |

## Search and keys

- **Ctrl+K** searches pages and every individual setting (label, help text, key). Up / Down, Enter opens the result and highlights the row. Esc clears.
- **Ctrl+J** opens or closes the Output drawer. **Ctrl+Q** closes the window.
- A setting that differs from its default shows a **changed** badge and a **Reset** button (`kurenai-conf reset KEY`).

## Where settings live

| File | What |
|---|---|
| `~/.config/kurenai/settings.json` | only the settings you changed, one per line (the shell and lock screen read it live; the lock screen on its next start) |
| `~/.config/kurenai/binds.conf` | your bind changes, `DEFAULT CHORD => NEW CHORD` (or `-` for off) |
| `~/.config/kurenai/hypr.conf`, `hypr.applied` | monitor and input choices; the last confirmed copy |
| `~/.config/hypr/kurenai-hypr.lua` | generated by `kurenai-hypr apply`. Do not edit by hand |
| `~/.local/share/kurenai/launcher.json` | favourites and recents |

Deleting `settings.json` puts every setting back to its default. `kurenai-conf export FILE` / `import FILE` move the first two files between machines (the archive is checked before anything is replaced).

## Display and input: the safety timer

A wrong monitor rule can leave a black screen. **Apply** writes the generated file, reloads Hyprland and starts a 15 second timer **in a background process**. Press **Keep** to confirm. If you do nothing (or the screen is unreadable), the last confirmed settings come back by themselves, even if this window is gone. The first Apply also adds one marked line (`KURENAI-HYPR-HOOK`) to `hyprland.lua`, after a backup. Your own `hl.monitor` lines are not edited; the generated file loads last and monitor calls are cumulative, so what you set here wins for that output. Switching off your only monitor is refused.

## What this window deliberately does not do

- It does not run `sudo`. The lock-screen hardening page only **prints** the steps.
- It does not send test notifications, open files, or run programs that are not `kurenai-*` (Do Not Disturb stays in the shell's quick settings).
- It cannot start the shell if `qs` is missing; it says so.

## Known limits

- The **Shortcuts page** of the shell reads `hyprland.lua` and the KURENAI files statically, so it still lists the **default** chord for a bind you remapped. The keys themselves work; the list is just not updated yet.
- If your `kurenai-binds.lua` is an older copy you edited (the installer keeps those and writes `kurenai-binds.lua.new`), it does not read `binds.conf`: remaps have no effect until you merge. `kurenai-conf binds set` says so.
- Icons are Nerd Font glyphs ("JetBrainsMono Nerd Font", like the shell). Without that font they show as empty boxes; the text stays readable.

## Verified, and not

- **Run in a sandbox:** every page loads in an offscreen Qt Quick test rig with **stand-in Quickshell modules** (`FileView`, `Process`, `DesktopEntries`, `StdioCollector`) that really run the `kurenai-*` scripts in a throwaway home with a fake `hyprctl` and `awww`. Scripted real mouse clicks and key presses: change a setting, Reset, two-click confirm, remap a bind by typing, string / number / list / choice rows, wallpaper click, favourites add / remove, the Display apply and Keep flow, search and jump. The shell scripts have their own tests (`kurenai-conf` 69, `kurenai-hypr` and hooks 37).
- **Not run:** in real Quickshell on your machine (it has not been started under `qs`), on a real Hyprland, with a real `matugen`, `awww`, fingerprint reader or second monitor. The stand-in `Process` is not Quickshell's, so stream timing (the window waits for both output streams, with a 0.6 s fallback) is the part most worth watching. If a page shows "could not be loaded", run `kurenai-settings --debug` and send me the first error.
